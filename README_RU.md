# AI Army — Fabric 26.2 (версия 0.3.1)

Исходники мода, переписанные под Minecraft 26.2: официальные имена Mojang и Fabric Loom 1.18.
Это **исходники, не готовый мод**. Чтобы получить файл `.jar` для папки `mods`, проект нужно собрать.

## Что изменилось по сравнению с прошлой версией
- Сборка устроена как в официальном шаблоне Fabric для 26.2 (`fabric-example-mod`, ветка `26.2`).
  Строка с Yarn-маппингами удалена: для 26.x их больше не выпускают.
- Добавлен Gradle Wrapper (`gradlew`). Ставить Gradle вручную больше не нужно, только JDK 25.
- Код переписан на имена Mojang. Мобы, TNT и черепа создаются через ванильные команды
  `/summon`, `/tp` и `/kill`. Так мод меньше зависит от внутренних классов игры, которые часто меняются между версиями.
- Армии помечаются тегом `aiarmy_army_N`. `/aiarmy delete` удаляет юнитов по этому тегу.

## Сборка через GitHub Actions (без установки чего-либо)
1. Создайте пустой репозиторий на github.com.
2. Загрузите туда **содержимое** папки `AIArmy_Fabric`, включая скрытую папку `.github` и папку `gradle`.
   Через сайт удобнее всего так: «Add file → Upload files», затем перетащить файлы.
3. Сборка запустится сама. Если не запустилась, откройте вкладку **Actions**, выберите **Build Fabric mod** и нажмите **Run workflow**.
4. Когда появится зелёная галочка, откройте запуск и внизу скачайте артефакт **AIArmy-Fabric-26.2**. Это zip.
5. Распакуйте его. В `mods/` кладётся файл `AIArmy-Fabric-26.2-0.3.1.jar`.
   Рядом в `mods/` должен лежать Fabric API для 26.2.

Если сборка упала (красный крестик), откройте шаг **Build** и скопируйте строки с `error:`. По ним ошибку обычно можно исправить за один заход.

## Сборка на своём компьютере
Нужен JDK 25. Затем в папке проекта:
- Windows: `gradlew.bat build`
- macOS/Linux: `./gradlew build`

Готовый JAR появится в `build/libs/`.

## Орбитальные жезлы (раздел 58 ТЗ v1.2)
Код жезлов находится в `OrbitalSystem.java`.

**Общее**
- Выдаёт жезлы только OP: `/aiarmywands`. Использовать выданные жезлы может любой игрок.
- Жезл работает только при точном имени `AI Army Orbital: <Тип>`. После переименования он перестаёт работать.
- ПКМ начинает операцию, повторный ПКМ тем же жезлом подтверждает. Смена слота отменяет операцию.
- Цель — блок под прицелом в момент подтверждения, а не поплавок. Дальность настраивается, по умолчанию 160 блоков.
- После успешного применения жезл ломается, даже с Mending. Если сработал лимит или перезарядка, жезл остаётся.

**Nuke.** 661 TNT: 1 в центре и 660 в 8 кольцах (24/40/56/72/88/104/120/156) радиусами 7.6–58.6.
Радиусы рассчитаны так, чтобы зоны взрыва соседних колец перекрывались (No Safe Spots, зона взрыва принята за 4 блока),
а между кольцами оставалось ~7 блоков. Покрытие проверено расчётом на сетке, при запуске мод перепроверяет геометрию и пишет результат в лог.
Каждый TNT появляется на 50 блоков выше поверхности в своей точке. Его fuse рассчитан по физике падения так, чтобы взрыв произошёл в момент касания.
Лимит: 3 применения за 5 минут на армию.

**Stab.** Одна колонна TNT (ширина — одна взрывная область) от самой высокой точки зоны вокруг цели до бедрока.
Все заряды взрываются одновременно. Интервал, fuse и размер зоны задаются в конфиге.

**Strike.** 10 волн синих черепов Wither по 100 штук. Каждая волна летит со своего направления и под своим углом.
Точки попадания волны равномерно заполняют круг без запланированных промежутков. Количество волн, черепов, плотность и интервал задаются в конфиге.
Лимит: 1 применение за 5 минут на армию.

**Wolf.** 50 волков рядом с активатором, а не в точке прицела. Strength II, Speed II, Wolf Armor, приручены активатором.

**Boss.** 100 боссов: 1 в центре и 99 в 5 кольцах (9/15/21/25/29). Тип выбирает OP командой `/aiarmyorbital Boss Warden|Wither`.
Чтобы снизить нагрузку, боссы появляются по 5 за тик.

**Stasis.** Только для OP. Держа жезл в руке, введи `/aiarmyorbital Stasis <x> <y> <z>`. Телепортируется тот, кто ввёл команду. Перед телепортацией проверяется:
высота мира, граница мира, 2 блока воздуха, твёрдый пол без жидкости, магмы и кактуса.

**Кулдауны.** Stab, Wolf, Boss, Stasis — 25 с (в конфиге 20–30 с). Nuke и Strike — лимиты только для AI-армий, не глобальные.
На обычных игроков лимиты Nuke и Strike не действуют.

**Конфиг.** Файл `config/aiarmy-orbital.properties` создаётся при первом запуске.

**Что нужно проверить в тестовом мире** (ТЗ требует испытаний):
взрыв Nuke у поверхности и покрытие на плоском мире; шахта Stab до бедрока; Strike на обсидиане и в воде; нагрузка (TPS/MSPT) от Nuke, Strike и 100 боссов.

## Команды (в игре, нужны права оператора / читы)
- Жезлы: см. раздел выше.
- `/aiarmy create <amount> [skin]` — создать до 20 NPC-прокси (Villager). `skin` пока не применяется.
- `/aiarmy list`, `/aiarmy delete <army>`, `/aiarmy tell <army> <message>`.

## Ограничения прототипа
- Юниты — обычные жители, не fake players. Приказы сохраняются, но не исполняются.
- Список армий хранится в памяти и сбрасывается при перезапуске мира.
  Сами жители остаются в мире, и их можно удалить командой `/kill @e[tag=aiarmy]`.
